# 模拟器截图自验证

穿戴 UI 需要视觉验证时，**可以自行启动模拟器并截图验证**，不必等真机（2026-10-26 起授权）。

## 皮肤选择（按表的类型三选一）

| 项目 | 设备 | 模拟器皮肤 |
|---|---|---|
| `band/` | 小米手环9（192×490 跑道屏） | `xiaomi_band` |
| `band_pro/` | 小米手环9 Pro | `xiaomi_band_pro` |
| `circle_watch/` | 圆形手表（466×466 圆屏） | `xiaomi_s4` |

## 操作要点

- 用 aiot/模拟器 SDK 创建对应 VVD 并启动（createVVD + start）；多个 VVD 并存弹选择框时，喂一个回车取第一项。
- **截图走模拟器 gRPC `getScreenshot`**（127.0.0.1:855x 端口，无鉴权），截屏后不要用 Read 直接读图（sharp/GLib 会崩 Qoder），转成 ASCII 灰度或像素统计来判读渲染。
- 屏幕休眠截到黑帧时，先注入按键/触摸唤醒再截。
- 真机出包验证仍按 `tool/verify_rpk.py`：内容清单、双签名、编译产物含改动标记。

## 并发红线（保留）

`aiot` 进程共享 `../.temp_<项目名>` 临时目录（`UxConfig.js` 的 `output` 写死），两个并发 aiot 会互相拆掉对方的构建现场：

- 用户正在构建/预览同一项目时，**不要**并发启动自己的 aiot 构建或 `aiot start`；
- 启动前 `rm -rf ../.temp_<项目名>` 清残留半成品；
- 验证完及时停掉自己的模拟器会话，把环境还给用户。
